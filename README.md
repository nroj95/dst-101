# dst 101

a spoiler-conscious illustrated survival handbook for `don't starve together`.

`dst 101` adds an in-game handbook intended to help newer players understand the world without turning discovery into a walkthrough.

the handbook covers practical survival, exploration, creatures, seasons, equipment, farming, sailing, caves, and other systems through short illustrated pages written from the perspective of an experienced explorer. it does not prescribe a correct way to play:

> give the player enough information to make a decision while leaving the decision and discovery to them.

> `dst 101` is an unofficial fan-made project. it is not affiliated with or endorsed by klei entertainment.

## using the handbook

`dst 101` is a client-only mod: only you need it, and the server does not. this repository is the development copy, listed in the game's mods menu as `dst 101 (dev)`.

open the handbook with **B**, or with the handbook button beside the map controls; its tooltip shows the current key. the key, an optional modifier, and whether the button shows are set in the mod's configuration (`modinfo.lua`). controllers open it with Menu Misc 3.

- **Contents** is where the handbook first opens. it lists every topic and page; pick one to read it, and `Tab` switches between Contents and the page you came from.
- **topics** sit in the sidebar. arrow keys or WASD move between topics and turn pages.
- **search** covers titles and page text. press `Enter` to start typing; the sidebar narrows to matching topics, and `Up`/`Down` step through them to the matching page. `Escape` leaves search, then closes the handbook.

by default the handbook reopens where you left it while you stay in the world. the `Handbook reopening` option can make it always open Contents instead.

the handbook follows the game's language where a translation exists and is English otherwise; the `Handbook language` option can choose one. translations are welcome — see [contributing](CONTRIBUTING.md#translations).

## project status

`dst 101` is approaching its initial public release. the main systems and initial content are in place, and current work is refinement, testing, accuracy, visual consistency, and release preparation rather than more content.

## contributing

help is welcome, from a single clearer sentence to illustrations, code, testing, and translations. an issue saying which page feels off is already useful. see [`CONTRIBUTING.md`](CONTRIBUTING.md) for a quick start.

## ai assistance

`dst 101` has been developed with substantial assistance from generative ai, used throughout the project for:

- drafting and revising handbook text.
- researching and organizing gameplay topics.
- reviewing page structure and project documentation.
- assisting with code and development workflows.
- generating and iterating on handbook illustrations.

the project is still manually directed, reviewed, edited, tested, and curated. gameplay information is checked rather than treating generated answers as authoritative, and generated illustrations are selected, revised, and corrected rather than treated as automatically final. that is why human editing, art review and testing are the most valuable contributions.
